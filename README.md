<h1>Frosty's Ice Cream  🍨</h1>

A front-end project for a simple restaurant website, built as part of The Odin Project curriculum. This project focuses on utilizing modern JavaScript to load website content dynamically, manage different page tabs, and demonstrate effective use of modules to keep the code clean and organized.

Whether you're a patron looking for a sweet treat or a developer looking for a practical example of dynamic front-end development, you've come to the right place!

<a href="https://dd3lim0.github.io/Restaurant-Page/"> 🚀 Live Demo </a>


Check out the live tavern!
✨ Features

    Dynamic Tab Navigation: Easily switch between the Home, Menu, and Contact pages without a full page reload.
    Modular Design: The codebase is organized into separate JavaScript modules for each page, ensuring a clean separation of concerns.
    Responsive Interface: A clean and modern UI that works well on both desktop and mobile devices.
    Content-Rich Pages: Each tab is populated with mock content, including menu items, a contact form, and a welcome message.
